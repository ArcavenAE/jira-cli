### New instance of cross-story sibling drift class (PG-F4-4)

This instance is distinct from the blast-radius underestimate class described in the original issue body: it involves a **semantic contradiction between two cross-story doc artifacts** rather than a numerical undercount. The contradiction was invisible to per-story adversary passes because each pass is scoped to its own story's file set.

**Observed instance:**
During wave-C delivery (S-577-4 comment-edit core + S-577-6 comment-view), the cross-story doc artifact `docs/specs/comment-crud.md` contained a contradiction between:
- The `visibility-field` section (authored during S-577-4 spec work) which described the wire shape of the `visibility` object as `{"type": "role", "value": "..."}`.
- The `merged-wire-shape` section (authored earlier during S-577-2 spec work for comment-add) which described the same field differently.

The contradiction was invisible to both the S-577-4 adversary (which saw the `visibility-field` section as authoritative) and the S-577-6 adversary (which saw the `merged-wire-shape` section as authoritative). Neither adversary pass cross-references the sibling section in `comment-crud.md`.

**Detection:** Caught at wave-C integration pass 1, after both PRs had been merged to `develop`. Required a separate fix pass.

**Cost:** 1 extra integration adversary pass + 1 fix round on a doc artifact that shouldn't have needed post-merge correction.

### Proposed complement to wave-integration adversary (extends current issue)

The cross-story sibling drift issue describes single-artifact blast-radius underestimates. The proposed complement addresses **multi-artifact cross-story contradictions** that only become visible when the full wave's doc artifacts are read together.

**Wave-integration review checklist addition:**

> For any wave that delivers multiple stories contributing to the same cross-story doc artifact (feature spec, JSON output shapes registry, wire-shape catalog, CHANGELOG section), the wave-integration adversary pass MUST include a **union-audit** step:
> 1. Identify all cross-story doc artifacts touched by any story in this wave.
> 2. Read each artifact in full (not just the sections the current story modified).
> 3. Check for semantic contradictions between sections authored by different stories.
> 
> This step is explicitly outside the scope of per-story adversary passes and MUST be added to the wave-integration checklist as a distinct named step.

**Severity of gap:** LOW per instance; compounds to MEDIUM in multi-story waves where cross-story doc artifacts serve as integration contracts.
