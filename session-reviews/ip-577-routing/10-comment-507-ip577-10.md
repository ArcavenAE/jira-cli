## SOH-COMMENT-CRUD-1 cycle datapoint — relocation-class stories and BC Source citations (IP-577-10)

**Source:** jira-cli SOH-COMMENT-CRUD-1 session review 2026-07-15 (IP-577-10)

---

### Relocation stories as a specific sub-class of peer-artifact sweep gap

A **relocation story** is a story whose primary task is moving an existing handler or module to a different file path (e.g., extracting a handler cluster from `workflow.rs` into `interactions.rs`). These stories have a specific, predictable peer-artifact sweep obligation that the current story template and fix-round protocol do not call out: **every BC Source citation that referenced the old file path must be updated to the new path atomically with the relocation**.

**Observed instance (S-577-1, PG-F4-2):**

Story S-577-1 relocated `handle_comment` and related functions from `src/cli/issue/workflow.rs` to the new `src/cli/issue/interactions.rs` shard. The story correctly implemented the relocation. However, 10 BC Source citations across `.factory/specs/prd/bc-3-issue-write.md` still referenced `workflow.rs::handle_comment` after the merge.

These 10 stale citations were not caught by:
- The S-577-1 adversary (scoped to the story's file set, not the factory spec directory)
- The relocation story's task list (no BC citation sweep task was included)
- CI (the `check-bc-citation-symbols.sh` guard validates that cited symbols exist, but does not check that the cited *file path* is the current location — it allows the symbol to be accessible from either path during the transition)

**Detection:** The stale citations survived through wave A, wave B, wave C, and into wave D, where they were finally caught by the adversary during a BC Source sync reminder (DEC-170 bundle-close obligation). Required a separate factory-artifacts commit (`7970ec1`) in the F7 burst — after all feature PRs had already merged.

**Cost:** 9 extra stale BC Source citations carried for the entire bundle duration; caught only at F7.

---

### Proposed fix (extends current #507 scope to relocation class)

**Story-writer checklist addition for relocation-class stories:**

> If this story relocates a handler, module, or public symbol from one file to another, add a mandatory delivery task:
> ```
> - [ ] BC Source citation sweep: grep -r "old/path.rs" .factory/specs/prd/ and update all matches to new/path.rs::new_symbol_name.
> ```
> This task must be completed BEFORE the PR is opened, not after. The sweep covers: `**Source:**` lines in all `bc-*.md` files, `**Trace:**` lines, and any rustdoc citations in `CLAUDE.md`.

**Severity:** LOW per instance; these stale citations persist for the entire bundle duration (potentially weeks) before being caught at F7 consistency audit, creating a false impression that BC Source coverage is current.
