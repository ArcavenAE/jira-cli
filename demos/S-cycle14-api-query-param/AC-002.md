# AC-002 — Repeated same-name params, and comma-in-VALUE (Behavior 2, Postcondition 4)

**Traces to:** BC-X.16.001 Behavior 2, Postcondition 4; EC-X.16.001-12/13.

## What this demonstrates

Repeated `-q NAME=...` occurrences are ALL sent, in flag order — no deduplication, no
last-wins/first-wins collapsing. The clap field is a plain `Vec<String>` with no
`value_delimiter`, so a comma inside one VALUE is never split into multiple pairs.

     occurrence, ONE pair; the comma is ordinary VALUE content, percent-encoded once (never split

Both commands exit 0; the mock's `query_raw` field shows the wire-exact assembled string.
