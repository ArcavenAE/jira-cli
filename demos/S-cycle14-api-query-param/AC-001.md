# AC-001 — Query-string detection/merge algorithm (Behavior 1, Postcondition 2)

**Traces to:** BC-X.16.001 Behavior 1, Postcondition 2; EC-X.16.001-1/4/5/8/9/12/14.

## What this demonstrates

`src/cli/api.rs::append_query_params(path, pairs)` — the new pure function that assembles every
`-q`/`--query-param NAME=VALUE` pair into a percent-encoded query string and merges it onto
`<path>`'s pre-fragment part. Detection considers only the text before the first `#`; the
`?`-presence check runs before any `&`-termination check.

## Recordings

- `AC-001-fresh-query.tape` / `.gif` / `.webm` — `jr api /rest/api/3/search/jql -q jql='project =
  FOO ORDER BY created' -q maxResults=5`. No `?` yet present — a fresh leading `?` introduces the
  query. Demonstrates the percent-encoding itself: space → `%20`, `=` inside the VALUE → `%3D`.
- `AC-001-merge-existing-query.tape` — `jr api '/x?a=1' -q b=2` → `?a=1&b=2` (EC-X.16.001-4: a
  non-empty, non-`&`-terminated existing query is `&`-joined).
- `AC-001-bare-terminators.tape` — `?`-terminated (`/rest/api/3/search?` + `-q new=2` →
  `?new=2`, no separator) and `&`-terminated (`/rest/api/3/search?a=1&` + `-q new=2` →
  `?a=1&new=2`, no separator) forms (EC-X.16.001-8) — never `?&`/`&&`.
- `AC-001-fragment.tape` — `jr api '/s#f' -q k=v`; the assembled query is inserted BEFORE the
  `#fragment` and the fragment is passed through verbatim (EC-X.16.001-5). The mock server's
  `fragment_received_by_server` field is always empty, corroborating RFC 9112 §3.2: a fragment is
  never transmitted to the server at all, regardless of `jr`'s own path-building.
- `AC-001-literal-qmark-in-value.tape` — `/s?jql=why?` + `-q k=v` → `&`-joined, never mistaking
  the trailing literal `?` in existing query CONTENT for an empty-query-component delimiter
  (EC-X.16.001-9).
- `AC-001-no-dedup-collision.tape` — `/s?fields=summary` + `-q fields=status` → both sent, no
  dedup/override, pre-existing text passed through unmodified (EC-X.16.001-12, D-380).

## Result

Every case exits 0; the mock server echoes back `query_raw` — the exact, still-percent-encoded
query string received on the wire — so the assembled output is visible directly, not just
asserted.

## Verdict

**PASS** — separator/merge algorithm behaves per Behavior 1/Postcondition 2 across all six
recorded cases.
