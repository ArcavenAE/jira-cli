219:- **`rust-toolchain.toml` outranks `rustup default` — msrv job requires `RUSTUP_TOOLCHAIN` env (S-626-1):** When `rust-toolchain.toml` is present in the working directory (as it is in this repo, with `channel = "stable"`), it outranks `rustup default` in rustup's precedence chain. Rustup precedence, highest to lowest: `+toolchain` > `RUSTUP_TOOLCHAIN` env > directory override (`rustup override set`) > `rust-toolchain.toml` > `rustup default`. (Note: directory overrides and `rust-toolchain.toml` are additionally ranked by proximity to cwd — a nearer file beats a farther override — but this is immaterial in CI where no directory override exists.) The pre-fix `msrv` CI job pointed at the tip of dtolnay's `1.85.0` version branch, which hard-codes the toolchain version and has no `toolchain` input declaration. The action correctly installed 1.85.0 and set it as `rustup default`. `cargo check` then ran in the repo root where `rust-toolchain.toml` (`channel = "stable"`) outranked `rustup default`, so the check silently ran under stable — a false-green. Because the old SHA had no `toolchain` input, adding `with: {toolchain: "1.85.0"}` alone would have been silently ignored by GitHub Actions (at most an "Unexpected input(s)" warning); the SHA replacement to `fa04a1451ff1842e2626ccb99004d0195b455a88` was a hard prerequisite — this version of the action declares `toolchain` as a required input. The fix adds both `with: {toolchain: "1.85.0"}` (to install the correct toolchain) AND `env: {RUSTUP_TOOLCHAIN: "1.85.0"}` on the `cargo check` step — `RUSTUP_TOOLCHAIN` outranks `rust-toolchain.toml`, ensuring cargo uses 1.85.0 at check time. Both are load-bearing — the action input installs the toolchain; the env override ensures `cargo check` uses it. Omitting the env override silently reverts to stable validation. Note: at the currently pinned SHA (`fa04a1451ff1842e2626ccb99004d0195b455a88`), the action validates `toolchain:` as a hard-required input — dropping the `with:` block fails the job loudly. The only genuinely silent revert vector is removing the `RUSTUP_TOOLCHAIN` env override.
