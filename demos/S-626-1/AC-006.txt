218:- **`rust-toolchain.toml` outranks `dtolnay/rust-toolchain`'s `toolchain` input — MSRV job requires `RUSTUP_TOOLCHAIN` env (S-626-1):** When `rust-toolchain.toml` is present in the working directory (as it is in this repo, with `channel = "stable"`), it overrides `rustup default`, `rustup override`, and the `toolchain` input of the `dtolnay/rust-toolchain` action at the shell level. Result: the MSRV CI job (`ci.yml` msrv job) installed Rust 1.85.0 via the action's `toolchain: "1.85.0"` input but then ran `cargo check` under stable because the toml's `channel = "stable"` re-asserted at process start — a silent false-green. The correct fix is `env: {RUSTUP_TOOLCHAIN: "1.85.0"}` on the `cargo check` step: `RUSTUP_TOOLCHAIN` is a process-level env variable that outranks `rust-toolchain.toml` (it is the highest-precedence override in the rustup precedence chain). Both the `with: {toolchain: "1.85.0"}` input AND the `env: {RUSTUP_TOOLCHAIN: "1.85.0"}` are load-bearing — the action input installs the correct toolchain; the env override ensures `cargo check` uses it. Omitting the env override silently reverts to stable validation.
