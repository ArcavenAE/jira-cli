AC-007: adf_to_text failure → exit 64 (EC-3.5.010-2a) — two-tier test

NOTE: the >256-deep wiremock fixture approach is unproducible. A ≥129-deep JSON body is
rejected by serde_json::from_slice (serde default recursion limit = 128; called in
client.rs::get) before adf_to_text is called — resulting in JrError::Json → exit 1, NOT
exit 64. The adf_to_text depth-guard exit-64 path is therefore unreachable via the
HTTP/wiremock boundary. EC-3.5.010-2(a) is pinned at unit level per tier (i).
