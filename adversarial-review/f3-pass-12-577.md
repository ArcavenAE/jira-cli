## F-1 LOW: AC-008 grep blind to multiline .args() flat-form invocations

**Story:** S-577-1
**Severity:** LOW
**Status:** FIXED in fix round 13

**Finding:** AC-008's verification method used a single-line grep to detect remaining flat-form `comment` invocations. This grep is blind to multiline `.args(["comment", …])` chains — the e2e clean-skip logic would mask survivors, giving a false-clean signal post-migration. Two failure modes: (a) multiline invocations span lines and evade the pattern; (b) any un-migrated site that happens to be in a skipped e2e block would not be caught at runtime.

**Fix applied (round 13):** AC-008 rewritten with:
1. 9-site explicit enumeration — authoritative list of all flat-form invocation sites known at story-write time, each with file path and context
2. Surface-guard subset-test backstop — `test_parser_paths_are_subset_of_surface_table` (in `tests/e2e_cli_surface_guard.rs`) goes red on any un-migrated site post-AC-007, providing an automated CI catch independent of grep correctness
3. Grep demoted to labeled supplementary check with explicit acknowledgment of its multiline blind spot
