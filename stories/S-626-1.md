In `.github/workflows/ci.yml`, the `test` job's `- name: Run tests (zero-test floor,
POL-11)` step (product commits `9312f11f` + `a247a343` + `84ab32ac`) replaces the
prior bare `- run: cargo test --all-features` step and implements:

1. **`CARGO_TERM_COLOR: never` step-level env override** — overrides the file-scope
   `CARGO_TERM_COLOR: always` for this step only, so the anchored
   `grep -E "^test result: "` pattern matches clean ASCII output instead of
   ANSI-wrapped text (TD-VSDD-057 / prism PR #127 anti-pattern).
2. **Captured, tee'd output** — `cargo test --all-features` runs under
   `set -euo pipefail`, piped through `tee "$RUNNER_TEMP/cargo_test_out.txt"`, so a
   genuine test failure still fails the step via pipefail propagation.
3. **`set +o pipefail` bracketing around the count computations** — the binary count
   (`wc -l`) and the summed passed-count (`awk`) run with pipefail disabled, so a
   `grep` no-match (exit 1) cannot abort the step before the diagnostic branches
   execute; `set -o pipefail` is restored before the three gate checks below.
4. **Three independent gate checks**, each emitting a canonical `FAIL (POL-11): ...`
   message and `exit 1` on violation:
   - **Binary-count floor**: `[ "${binaries}" -lt 90 ]` — fails if fewer than 90 test
     binaries reported results (catches mass orphaning of `tests/` files; a bare
     `passed-count > 0` predicate is inert here because `src/` inline
     `#[cfg(test)]` tests, ~1,100 at head, keep the passed-count positive even when
     every `tests/` binary is orphaned).
   - **Named canary**: `grep -q "ci_gate_completeness" "$RUNNER_TEMP/cargo_test_out.txt"`
     — fails if the `tests/ci_gate_completeness` binary did not run (catches the
     self-orphaning case: the binary carrying the CI-gate Rust regression pins stops
     running while the binary count stays above 90).
   - **Zero-test floor**: `[ "${total}" -eq 0 ]` — fails if the summed `passed`
     count across all binaries is zero.
5. **Positive-coverage assertion** — on success, emits a runtime-computed
   `"Check passed: ${total} tests executed across ${binaries} test binaries"` line;
   exit code alone is treated as insufficient proof under POL-11 policy.

**Acceptance check:** Both proof directions execute cleanly. Positive path (measured
